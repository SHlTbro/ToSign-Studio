# 从名单到可导出的成品

先选择已审核底图和合适的布局模板，再填写姓名、祝福语、字形来源与墨色。提交时，服务端核验并冻结这批参数，以幂等键识别同一次提交。内置队列逐项生成图片；生成成功之后还需要逐张质检，通过后才能导出 PNG 和 ZIP。

![正常生成与失败恢复](../../assets/diagrams/workflow.png)

生成成功只是“有一张图片”，不是“成品质量合格”。审核拒绝会保留原图和记录，不能作为已审成品导出。导出重新核对当前版本及图片字节；修改图片会撤销旧审核。

若参数或模型执行资格不可用，当前提交停止；只有用户明确允许回退的字形策略才会使用并记录真实回退来源。发生失败或取消时保留原任务，页面回读后可恢复失败项。提交结果不明时，先查询同一个任务，避免把等待超时误判为“没有创建”。受控恢复会建立关联的新任务，不覆盖原失败。

图中的泳道表达业务阶段，不是三个独立服务。失败和回读恢复来自 render/service.py 的幂等创建、单项重试及版本化审核与导出行为；前端对应 P5_Batch.vue 与 P5_Review.vue。
